# Agent marks

Marks are embedded in `src/provider-marks.js`; showing them makes no network request.

- Cursor cube: unmodified path from `General Logos/Cube/SVG/CUBE_2D_DARK.svg` in the [official brand kit](https://cursor.com/en-US/brand). Fill follows the surrounding foreground so the same mark works in light and dark.
- Claude Code mascot, OpenAI, OpenCode, Gemini, Windsurf, Goose and Cline: SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), MIT. Claude uses `claudecode.svg`, not the Claude chat starburst. Provider names and marks remain their owners' trademarks.
- Continue: `extensions/intellij/src/main/resources/icons/continue.svg` from the [official Continue repository](https://github.com/continuedev/continue), Apache-2.0.
- Separate 12 px status glyphs: spinner, pause, check and error. Logos never rotate.
