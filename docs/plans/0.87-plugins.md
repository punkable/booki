# 0.87 implementation status

The supplied plan is implemented in the plugin/widget changes on this branch. This document describes the controls and their setup boundaries; it does not claim that a release has been published or that physical hardware has been tested.

## Common catalog

`src/plugin-catalog.json` is shared by Rust and Settings. Each managed tool has an exact release and asset name, a SHA-256 check, and a folder under `%LOCALAPPDATA%\Booki\plugins\<id>`. OpenRGB's official distributor is Codeberg; its archive hash is pinned in the catalog. GitHub assets use the pinned release's published digest. Both paths retain checksum verification. Install/remove operations are serialized. ZIP relative directories are preserved, unsafe paths and symbolic links are rejected, expanded size is bounded, and replacing an installation rolls back when the final rename fails.

Cards name the feature they feed. Widget detail panels offer an install action when a managed provider is missing. Readings/actions name their provider. Downloading a tool does not run it.

| Provider | Connection in Booki | Setup / limits |
| --- | --- | --- |
| HeadsetControl 4.1.0 | Device batteries, including USB-receiver headsets | Exact portable Windows executable, not the installer; actual headset compatibility depends on upstream support. |
| yt-dlp 2026.08.19 | Drop a browser link on the dock or paste it into the Media panel | Choose a download folder before starting. Single-video, single-file format; no playlist, config execution, FFmpeg merging, or credential collection. Upstream site/extractor restrictions still apply. |
| winget | System panel: list available app updates | Uses the existing Windows App Installer alias. Booki does not install/uninstall winget or update apps automatically. App Installer and any required source agreements must already be set up. |
| OpenRGB 1.1 | System panel: open the GUI or apply an `.orp` lighting profile | Uses the official portable distribution with its Qt resource directories preserved; supported hardware is required. |
| Rclone 1.75.2 | System panel: transfer status via Rclone RC | Requires an existing RC service on `127.0.0.1:5572`. Booki does not create cloud accounts, store credentials, or start sync jobs. |
| LibreHardwareMonitor 0.9.6 | System panel: temperatures and fan speeds | Open explicitly as administrator, then enable its web server on `127.0.0.1:8085`. Installation and the panel show the administrator/Defender-driver warning. Booki remains unelevated and never changes Windows protection. |

## Native widgets

System retains its native CPU/memory snapshot. Volume uses Windows Core Audio directly, including separate session identifiers for app volume/mute; EarTrumpet is not embedded. System, Volume, Devices, Battery, AI and Media open detail panels. Existing clock/calendar/weather/focus panels remain. Late responses cannot resurrect a closed panel. Media retains explicit previous/play/next controls and gains optional video downloads.

Windows browser-link drops use an OLE target because WebView2's file-only interception discards link formats. Explorer file drops retain their targeting events and physical coordinates. A drop opens the Media action; it never starts a download by itself.

## Appearance and motion

See [Fluent themes and motion](../design/fluent-themes.md) for Microsoft's actual WinUI resource references. Automatic surfaces use layered grays. A continuous shared damped spring replaces the width-then-height animation and covers both directions and all edges. Reduced motion and high contrast remain supported.
