# 0.95.0: comprobación pendiente en Windows

Estas pruebas requieren la aplicación instalada y hardware real. No se marcan
como realizadas por pasar Playwright, Clippy, tests nativos o el empaquetado CI.
Registrar versión de Windows, arquitectura, escalas de pantalla y conexión del
periférico; no adjuntar registros de cuentas ni credenciales.

| Caso | Procedimiento | Resultado esperado | Estado |
| --- | --- | --- | --- |

| Menús y personalización | Abrir Personalizar desde el grupo y su cabecera; desplegar una paleta, cancelar, aplicar y recorrer listas largas con Volver/Escape | Nombre/icono/color en un panel pequeño; menús acotados, foco restaurado y sin reiniciar los otros widgets | Pendiente |
| Arrastre visible | Sacar un miembro hacia otro grupo o entre dos elementos; repetir y pulsar Escape | Icono/nombre/destino visibles, inserción clara; cancelar conserva el origen | Pendiente |
| Teclado y vistas | Ctrl + rueda, buscar, flechas y Home/End; cerrar y abrir | Vista guardada, navegación entre resultados visibles, búsqueda conservada durante la sesión | Pendiente |

Los fallos encontrados deben registrarse con pasos reproducibles y un resultado
observado. Consultar una batería más a menudo no obliga al dispositivo ni a
Windows a producir una lectura nueva. La validación de una actualización firmada
solo puede realizarse cuando exista el instalador definitivo de esta versión.
