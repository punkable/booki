# Booki 0.87.0

Optional tools work through one catalog, widgets open useful controls, and the dock and dynamic notch share a smoother shape transition.

## Plugins and controls

- **HeadsetControl download fixed.** Booki now selects the official portable Windows executable. The previous installer looked for a ZIP that the pinned release does not publish. Downloads retain SHA-256 verification.
- **One catalog.** HeadsetControl, yt-dlp, OpenRGB, Rclone and LibreHardwareMonitor have pinned versions, verified downloads, their own folders and a Remove action. ZIP packages keep their runtime subdirectories. A failed replacement preserves the previous copy.
- **Widget details.** Click System, Volume, Devices, Battery, AI or Media to open details and controls. A missing optional provider offers an install button. Readings identify the provider they came from.
- **Volume by application.** The Volume panel uses Windows Core Audio sessions on the default output, with individual volume and mute controls. Refresh finds apps that started playing after the panel opened. No EarTrumpet integration is required.
- **Video downloads.** Drop an HTTP/HTTPS video link on the dock or paste it into the Media panel. Choose a destination before yt-dlp starts. Booki downloads one video in a single-file format; it does not start playlists, merge formats with FFmpeg, or collect sign-in credentials. Support still depends on the site and yt-dlp's extractors.
- **App updates.** The System panel can list updates through the winget already managed by Windows App Installer. Booki does not install app updates automatically or remove winget.
- **Lighting.** Open OpenRGB or apply a saved `.orp` profile from the System panel. Profile failures are reported.
- **Cloud transfer status.** Rclone reads an existing local RC service on `127.0.0.1:5572`. Booki does not configure cloud accounts or start sync jobs.
- **Temperatures and fans.** LibreHardwareMonitor supplies readings after you open it and enable its local web server on `127.0.0.1:8085`. Its card explains the administrator requirement and possible Defender driver alert before installation and opening. Booki stays unelevated and does not change Windows protection.

## Appearance and motion

- **Comfortable light and dark themes.** Settings, dock, notch and panels use layered neutrals based on Microsoft's actual WinUI theme resources. Automatic dark glass uses an elevated gray instead of a near-black tint. User-picked colors remain available.
- **Continuous notch-to-dock motion.** Width, height, position and corners change together with a damped spring. The reverse transition follows the same path, including top, bottom, left and right edges. The previous separate vertical growth stage is removed. Reduced motion and high contrast remain supported.
- **Windows link drops.** The dock accepts browser links through Windows OLE while preserving Explorer file-drop targeting.

## Validation limits

Automated browser tests use a simulated native bridge; Windows CI runs native tests and builds x64/ARM64 packages. These checks do not establish real USB-headset compatibility, a physical audio-device switch, sensor-driver behavior, RGB hardware access, configured cloud transfers, or compositor frame rate on your PC. Those require device validation. ESLint 10 remains held until the React lint plugin supports it.
