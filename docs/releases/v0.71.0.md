# Booki 0.71.0

A redesigned library and settings workspace, with clearer editing and stronger protection for your data.

- Keep the dock editor visible while searching. A click selects an app; **+** or dragging adds it. Move apps into positions and groups, edit multiple items and undo changes.
- Discover apps through local Windows and Booki usage, with multiword search, abbreviations, executable aliases and small-typo matching. Catalog changes trigger a refresh; results are cached between visits.
- Configure dock position, auto-hide and notch together, with a shared preview and advanced controls tucked away. Choose curated finishes or configure widgets in a gallery and inspector.
- Use Booki context menus across the dock and panels. Settings is available from every menu, and its optional dock icon can be moved or removed. Delayed responses cannot reopen dismissed menus.
- Browse subfolders inside Booki, go back or open the current folder in Explorer. Failed page requests keep the previous entries available for retry.
- Receive native Windows notifications for media, volume and running windows. Recovery polling remains available, and hidden dock widgets stay suspended. Icon caches have explicit bounds.
- Save complete profiles, including general settings, with recovery copies and protected writes. Overlapping edits offer a choice rather than silently overwriting newer settings. Historical default changes preserve existing preferences.
- Keep Windows clipboard history encrypted. Encryption or storage failures retain the previous copy and are reported in Settings; private entries remain excluded from disk history.

The update preserves existing configuration. Pinning shortcuts keeps their originals; moving them remains an explicit action. Updates download in the background and back up Booki data before installation.

## Installation

Use the x64 installer for Intel/AMD Windows PCs, or the ARM64 installer for Windows on ARM. The x64 MSI remains available for managed installation. Existing installations use Booki's updater; there is no need to install a second copy.

## Verification limits

Automated browser tests use a simulated Windows bridge. Native x64 tests and x64/ARM64 packaging run in CI; ARM64 packaging is not runtime validation. Real two-monitor interaction, fractional DPI, GPU composition and before/after CPU or memory measurements still require a Windows device. No measured Windows performance improvement is claimed.
