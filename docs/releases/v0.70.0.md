# Booki 0.70 — Your workspace, your way

- A new Home dashboard with dock previews, quick actions and behavior scenarios. Settings navigation now groups related options and adapts to smaller windows.
- A visual widget gallery and previews shared with the dock. Choose widget widths, reduce transparency, and scroll crowded docks without shrinking your chosen icon size.
- Four new widgets: a local countdown timer, local tasks, monthly calendar, and city weather powered by Open-Meteo. Weather is optional and queries only your selected city; it does not request device location.
- A redesigned app library with search, local usage recommendations, running apps and paginated installed apps. Usage recommendations combine Windows' local record and successful launches through Booki; nothing is uploaded.
- Shortcut fixes from #64: pinning preserves originals, explicit moves preserve `.lnk` contents, dragging out offers return to desktop, and folder pages no longer stop at 80 entries. Smart auto-hide responds to Show Desktop; language changes refresh widget labels and menus.
- Safer partial configuration writes, cancelled drags that do not commit, coalesced native polling, display selection by stable name, and local diagnostics export that excludes personal widget content and paths.
- Update progress supports unknown download sizes and prevents duplicate installs. Historical release notes are expandable, the installer supports all five languages, and normal uninstall removes the startup entry while updates preserve data.

This update preserves existing settings and profiles. The Windows installer is still not Authenticode-signed; updater artifact signatures are a separate mechanism.

## Premium workspace refinements

- A quieter white/dark Settings workspace, coordinated glass/Mica/solid finishes, direct editing from Home and search that focuses the requested control.
- Windows packaged-app discovery and shortcut launch identities; recommendations consider usage and recency without merging unrelated apps that share a name.
- Select several apps across searches, hide recommendations, disable history-based suggestions or clear Booki's own launch history.
- Shared bounded icon caching, limited parallel extraction and asynchronous native app scanning.
- Editable tasks, calendar navigation, weather units and one-click restart of a completed timer.
- Download a signed update in the background, then explicitly restart to apply it quietly to the current installation. Settings and profiles are backed up first, and failed saves/backups block installation.
