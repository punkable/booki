# Booki 0.80.0

Booki rebuilt top to bottom: simpler, clearer and native to Windows 11.

- **Settings in five sections instead of nine.** Home, Dock, Widgets, Apps and System, in the style of Windows 11 Settings and on Mica when Windows offers it. Behavior, position, appearance and size now live together on the Dock page; profiles, updates, help and about live in System. The dock preview scales to fit and no longer has inner scrollbars.
- **Three real finishes.** Glass blurs what is behind it (with an intensity slider and an optional color; *Dark glass* replaces Tinted), Mica is opaque and lightly tinted by your wallpaper, and Solid has no transparency. Widgets take their plates from the finish instead of painting fixed black or white boxes.
- **No box behind rounded corners.** The native blur is now kept inside the dock's rounded outline even when Windows ignores the window's region.
- **Ten widgets.** *System* shows the CPU, memory, disk and network readings you choose, on one plate. *Focus* combines the timer and the task list. Clicking the clock opens the calendar. Uptime is retired.
- **A simpler notch.** It is an attached tab or a floating pill that always follows the dock, opened by click or hover. The adaptive dot, the size slider and the always-visible notch are retired.

Existing configurations, profiles and backups are converted automatically. Acrylic becomes Glass, Tinted becomes Dark glass with its color, pinned CPU, RAM, disk and network widgets become one System widget showing the same metrics, and timer and tasks become Focus with their tasks and timer intact.

## Verification limits

Automated browser tests use a simulated Windows bridge, and the native code was type-checked and linted against the Windows target from Linux. The new blur containment, Mica tint and notch geometry still need to be checked on a Windows 11 device.
