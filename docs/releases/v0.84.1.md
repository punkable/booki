# Booki 0.84.1

Fixes for the theme, the notch dot and how the dock opens from a live activity.

- **The theme you pick is the theme you get.** A light theme no longer paints a dark dock when Windows shows the accent color on the taskbar; that accent fill now applies only in dark. When the glass color sets its own text color (Dark glass, or the taskbar color), the whole dock and notch switch to the matching theme, so menus, flyouts, hovers and widget tiles no longer mix light and dark. In Settings, "System" follows the Windows app mode.
- **An even notch.** The resting notch (tab, live capsule and dot) no longer shows a band where it looked cut in half until you hovered it. Only the open card is blurred.
- **The dock grows out of the notch.** While the notch shows something playing, a timer or another live activity, opening the dock stretches that capsule out to the full bar instead of rising from the screen edge.

## Verification limits

Automated browser tests use a simulated Windows bridge, and the Windows CI builds and packages the app. The theme with an accent taskbar, the notch blur and the stretch animation need to be checked on a Windows 11 device.
