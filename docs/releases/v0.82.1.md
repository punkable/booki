# Booki 0.82.1

A fix for the Settings window.

- **Settings stays where you put it.** Changing the dock's position, alignment, monitor or edge gap no longer moves the Settings window. The dock moves on its own once the change is saved.
- **The close button always answers.** If your last change can't be saved, Settings now says so, with Retry and Close without saving, instead of ignoring the click. Pressing close again closes without that change.
- **Opening Settings again brings it back.** Opening Settings from the dock or the tray while it is minimized now restores it, and it opens at a size that fits smaller or scaled screens.
- **Fix updates stay quiet.** A patch update like this one no longer opens Settings on "What's new" after it installs.

## Verification limits

Automated browser tests use a simulated Windows bridge. Window placement, restoring a minimized window and the opening size need to be checked on a Windows 11 device.
