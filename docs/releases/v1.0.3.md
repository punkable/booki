# Booki 1.0.3

A notch that stays with you while you browse.

## Notch

- **Maximized windows.** The notch no longer disappears over a maximized window (a browser, for example). It stays, smaller and dimmed so it never covers your tabs, and keeps showing music, battery, timers and agents. It returns to full size when the pointer comes near, when you open its card or when something new happens. It only steps fully aside for real fullscreen: games, movies and presentations. ([#145](https://github.com/punkable/booki/issues/145))
- **Browser menus.** Opening a browser's extensions, history or downloads menu no longer makes the notch flicker in and out.

## Reliability

- A dock item whose path is empty shows a clear error instead of Windows' "cannot find the file".
- If one internal part of Booki fails, the rest keeps working instead of freezing.
- Dependencies updated with security fixes (zip, url, cookie, the updater plugin).

## Under the hood

- All five languages now live in one file each (`src/locales/`); Portuguese, French and German load on demand.
- The screen watcher moved out of `lib.rs` into its own module.

## Not verified on a Windows PC

Built and tested with a simulated Windows bridge and a Windows cross-compile. A real PC still needs to confirm the dimmed notch over a maximized Edge or Chrome window and that it steps aside in fullscreen video and games.
