# Booki 0.91.0

## AI usage without credentials
- Booki never reads, uses, stores or sends a Claude or ChatGPT credential, and the AI widget makes no network request.
- It reads only the usage logs that Claude Code and Codex already keep on your PC, read-only, and keeps no message content.
- **Codex** shows its real 5-hour and weekly percentages from its own logs.
- **Claude Code** shows the tokens used in the current 5-hour block, when the block resets, and the last 7 days. It shows no plan percentage, because the logs don't include one.
- A tool counts as detected when its folder exists. An idle one says "No activity in the last 5 h".

## Widgets and panels
- **Device cards:** a device's own card finds its device even when Windows names it differently by source (Bluetooth, Logitech, HeadsetControl), and keeps its last reading through a missed poll.
- **Panel placement:** panels, folders and menus stay within the dock's ends instead of overhanging them, and grow up into the space above.
- **Updates panel:** it is now a WinUI list.
  - Installs run one at a time, so you no longer get "another installation is in progress".
  - Each row shows its own progress or error. Skip is a quiet icon.
  - A row with an unknown current version shows "New version x".
- **Native blur:** an open folder's or panel's blur no longer stays floating when the dock tucks away.
- **Settings > Widgets:** each card shows the preview first, and a small check marks widgets already pinned, so names are no longer cut off.

Browser tests cover these flows. The AI logs, devices and native blur still need a real Windows PC to check.
