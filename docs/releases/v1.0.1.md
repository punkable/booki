# Booki 1.0.1

Polish where you spend your day. Groups that stay open, a volume mixer with real names and clearer editors.

## Widgets and groups

- **Back to the group.** Closing a widget you opened from a group takes you back to the group; clicking away still closes everything.
- **Group view size.** Changing the icon size inside a group no longer closes it, and its drop-down list matches the button.
- **Media becomes the app that's playing.** When the player is pinned, the Media widget shows its name, its icon when there is no artwork, and its panel has a button to open it.

## Settings

- **Widgets page like Apps & folders.** Your widgets as compact cards; the catalog opens in an **Add widget** dialog.
- **Group editor like a Windows 11 folder.** A big icon opens colour and icon, the name is edited right in the title, and the item count and actions sit beside it.
- **AI usage.** A new **Only those that show a quota** option hides providers without one and brings them back on their own once they report it. The Claude note now explains that only Claude Code in a terminal shares plan usage; the desktop app and VS Code don't leave it on your PC.

## Reliability

- **Volume mixer.** Each app shows its real name (from the session or the program's own description, not its browser engine), its icon, and the mute buttons are no longer cut off. Two sessions with the same name are numbered.
- The dock's hover label is lighter, and the README clips were re-recorded over a photo desktop.

## Not verified on a Windows PC

Automated tests run the interface in a browser with a simulated Windows bridge. A real PC still needs to confirm: app names and icons in the volume mixer, opening the playing app from the Media panel (Store apps open through their AppUserModelID), and the group view drop-down over the transparent dock.
