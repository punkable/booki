# Booki 0.92.0

## Claude and Codex in the notch
- The notch shows the tool's logo with "Claude working…", "Claude needs your permission" or "Claude finished" (and the same for Codex).
- It reads only the session logs Claude Code and Codex keep on your PC. It never opens credentials and makes no network request. Turn it off in Settings > Dock.
- "Needs your permission" is inferred when a tool call waits more than 6 s, so a slow command can show it too.

## Focus and Do not disturb
- Each Focus card can turn on Windows Do not disturb for the block (off by default). Booki only turns off a Do not disturb it turned on itself.
- Booki's own notices wait until the block ends; a very low battery still gets through. The dock can also stay tucked away during focus.

## Automatic backup
- Settings > System > Automatic backup: pick a OneDrive or Google Drive folder and Booki writes `Booki backup.json` there after each change. Restore reviews that copy before applying it.

## Fixes
- Right-click inside a widget panel opens that item's menu, drawn above the panel.
- Updates hides apps winget can't install ("no applicable update").
- Device batteries stay steady: Logitech's reading wins over Bluetooth, and a sudden jump waits for a second reading.
- Settings shows a spinner instead of a blank window while it loads; devices show a bolt while charging.
- The Cloud widget and the Rclone plugin are removed.

Browser tests cover these flows. Do not disturb, agent detection and batteries still need a real Windows PC to check.
