# Booki 0.95.1

A combined correction of the settings, capture, notch and widget regressions reported after 0.95.0, with additional fixes for notes, downloads and deferred notices.

## Settings and groups

- Optional style presets start collapsed, explain their effects and preserve notch activation and shape.
- Save status no longer overlaps conflict controls. Conflicts preserve affected drafts while unrelated settings save, retire when resolved remotely, and rebase edits made during a pending save.
- Widget settings open the exact instance, including grouped and duplicate widgets and an already-open Settings window.
- Panel ink, native select options, focus rings and error colors follow the actual surface tint, including light glass with a dark theme and Windows high contrast.
- A failed group-density save cannot discard a newer selection. A delayed translation load cannot override a newer language choice.

## Captures and notch activation

- Click activation waits for a click; delayed hover and hot-edge signals cannot reveal it. Keyboard access to playback controls remains available.
- When capture inclusion is enabled, a temporary hold preserves open panels, magnification and tooltips while Windows Snipping Tool has focus. Stale capture replies cannot dismiss newly held panels, and normal hiding resumes after capture.
- Capture detection checks only the foreground executable identity. It does not inspect captured images or account content. Existing recording inclusion policy is preserved.

## Reliable saves and quiet notices

- Failed optional previews and cross-window broadcasts do not label confirmed saves as unsaved or offer stale-snapshot retries.
- Explicit fresh-configuration recovery clears old conflict, close-error and callback state.
- Notes drain newer text after an older failed write, including when the newer autosave already joined the pending operation.
- Notices consult current Windows Do not disturb before delivery, recheck quiet mode when deferred delivery begins, and resume without a Focus widget. Temporary query failures retain the last known quiet state. Background retries run only while notices remain held.
- Notch actions prevent duplicate in-flight execution and remain retryable after failure.
- A download finishing before its cancellation command clears Cancelling and retains the saved file despite a late cancellation error. Rejected completion notifications do not block the queue.
- Plugin installation waits for terms acceptance to save, with an inline error and retry on failure.

Both READMEs, current release notes, download links and source captures are synchronized for this release. Captures use offline example icons and data.

Automated browser coverage uses a simulated Windows bridge. Physical Snipping Tool behavior, Windows Do not disturb, native glass, peripheral charging, mixed-DPI monitors and an installed upgrade from 0.95.0 remain unverified. Builds, packaging and updater signatures do not establish those runtime checks. See `docs/quality/settings-capture-regressions.md` for the manual cases.
