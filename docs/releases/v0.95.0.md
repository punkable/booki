# Booki 0.95.0

One combined refinement of the intelligent dock, groups, live tools and Collector.

## Find and move things with confidence

- Search inside groups without rebuilding their live widgets. Choose list, small, medium or large icons, or change density with Ctrl + mouse wheel. The view is saved; search and scroll are retained while reopening groups in the session.
- Dragged group members have a visible icon, name and destination preview, with insertion markers on the dock. Escape, focus loss and interrupted pointer capture cancel the gesture without moving the item.
- Context menus keep frequent actions in view. Customize opens a compact group editor for name, icon and color, with pickers expanded only on demand and Apply/Cancel. Organization, appearance, windows, recent files and profiles use bounded secondary views with Back and keyboard navigation.
- Keyboard arrows and Home/End navigate visible group entries. Internal scrolling keeps the search toolbar reachable.
- Smooth dock scrolling, restrained magnification and optional Integrated, Quiet and Expressive appearance presets refine daily interaction. Presets preserve pinned content, profiles and display selection.
- Move the dock between screens with its existing empty-area drag. The destination uses the native cursor's physical coordinates to avoid JavaScript DPI ambiguity.

## A quieter notch and more accessible tools

- Active agents use compact logos and state indicators, with full accessible labels. Waiting and error states have priority; relevant agents rotate, and a focus timer can alternate with nonurgent work.
- Music appears briefly when playback starts. Hovering a working agent retains recent music and play/pause controls without permanently expanding the notch.
- New installations use an idle dot and scrollable dock overflow. Existing explicit preferences remain in place.
- The common widget panel reuses live cards and their existing tools. Audio controls are available from the dock menu and searchable launcher actions, alongside widgets, settings, playback and named groups.
- Device details explain their source and query time. A new query does not guarantee a new hardware measurement. AI usage prioritizes agent activity and distinguishes real reported quota from approximate local token consumption.

## Collector, from link to saved file

- Explicit Auto, Video, Audio, File and Gallery modes, multiline links and a bounded 50-job session queue make its supported downloads discoverable.
- One native job runs at a time. Job-specific progress, indeterminate gallery progress, cancellation, retry and clearing finished results prevent late events from repainting another job.
- Folder, default media format and best/1080p/720p video quality are shared between the panel's gear, Widgets and Plugins. Quality caps also apply to fallback video formats.
- Completion offers Open folder, Open file and Copy path beside the dock or in a temporary notch popup while it is tucked away. The separate notch receives only labels and expiring callback tokens. Results remain actionable in Collector.
- The queue and its URLs/results stay in memory for the session. Cancellation waits for native work to stop; a stalled direct HTTP read may delay it. Retry can reuse supported partial media downloads, but universal pause/resume is not promised.

## Presentation and updates

- Booki's update notice stays discreet, with explicit download and install actions and existing focus/Do not disturb deferral.
- Both READMEs show current source captures with offline example icons and data, including actual group search, the widget panel and Collector queue. Versioned notes and recent history remain synchronized.
- Native-glass closing panels avoid an opacity transition after their native material has been removed.

Automated browser coverage uses a simulated Windows bridge. Native checks and CI do not validate physical peripheral charging, Windows compositor behavior, mixed-DPI monitor movement or an installed upgrade. Those checks still require Windows hardware; no claim is made that stale MX Keys readings or every glass flash has been eliminated.
