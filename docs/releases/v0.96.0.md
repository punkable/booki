# Booki 0.96.0

Widgets open their content, settings advance in steps, and notices respect the dock.

## Widgets that open and configure consistently

- Clicking any of the 15 widgets opens its content or controls, including inside groups. Media playback buttons and the volume wheel remain quick actions. Double-click no longer unexpectedly opens Settings.
- Context-menu Settings and panel gears target the exact instance. Duplicate widgets have an explicit instance selector.
- Content, Appearance and optional Connections tabs separate functional settings from visual choices, with accessible keyboard navigation and Previous/Next. The inspector stays reachable while the catalog scrolls.
- Functional preferences include clock format/seconds/date, calendar week start, weather city/units, device/provider selection and rotation, system metrics, focus duration and volume-wheel increment. Existing clipboard and Collector policies are clearly labeled as shared settings.
- Clock details include its current time, configured Weather opens its forecast, and System/Battery readings refresh while their panels remain open.
- Plugin cards name the correct widget and configure existing grouped copies instead of repeatedly offering Add Collector. Installation waits for acceptance to save.

## Clearer panels and AI discovery

- Clipboard help is collapsed behind an Info button, with direct settings and an internally scrolling history. Group search and view selection share compact icon-led controls. Device panels use consistent headers, visible detail affordances and separate content scrolling.
- Claude, Codex, Cursor and OpenCode always have a discoverable status in AI details. Local/custom homes, XDG locations and archived Codex sessions are considered. Cursor/OpenCode presence uses folder metadata; no account database or credential is opened to infer quota.
- The widget rotates detected providers and lets users select Cursor or OpenCode explicitly. Missing local data and unavailable allowance are explained instead of silently hiding the provider or inventing a percentage. AI details can be refreshed without restarting Booki.

## Notices and Windows integration

- Update notices and actionable download/battery notices share a measured lane outside the dock on all four edges. Placement includes the complete content and buttons, accounts for magnified icons and follows motion, size and viewport changes without an idle polling loop.
- The update notice has a dismiss button, retains its version across settings changes and exposes keyboard-accessible actions. Older asynchronous notice actions cannot dismiss or replace newer notices.
- Windows work-area origin changes trigger dock repositioning even when its dimensions stay unchanged. Widget settings link to relevant Windows sound, battery and date/time controls.
- CI validates both configured MSI languages and rejects stale versions or another edition’s installers.

Documentation, README download links, current notes and example frontend captures are synchronized for this version.

Automated browser tests use a simulated native bridge; native Windows tests, packaging and updater signature checks have separate results. A physical installed upgrade from 0.95.1, Windows notification/Do not disturb behavior, native glass, peripheral charging and mixed-DPI/multiple-monitor behavior still require a Windows PC. These are not established by CI. See `docs/quality/widget-workspaces.md` and `docs/quality/notifications-windows-audit.md`.
