# Booki 0.96.0

Windows 11 acrylic glass for each theme, a new widget gallery, smooth motion at any refresh rate and plugin updates.

## Widgets

- **New Widgets page.** The widgets on your dock sit at the top, shown as they look there, including those inside groups. Below, a gallery with categories (Time, System, Media, Tools), search and one-click **Add**. Settings open in a side sheet with a live preview and Content / Appearance / Connections tabs.
- **One click opens a widget.** Any of the 15 widgets opens its content, also inside groups. Right-click or the gear opens that copy's settings. Media playback buttons and the volume wheel stay quick actions.
- **Per-widget preferences.** Clock format, seconds and date; calendar week start; weather city and units; device and AI provider selection and rotation; system metrics; focus duration; volume wheel step.
- **Clearer panels.** One header for every panel with icon actions (refresh, Bluetooth, settings, close). Devices show when they were last read. System uses meter cards. Media shows what is playing with a centred transport. Focus uses Windows toggle switches.
- **AI usage.** Claude, Codex, Cursor and OpenCode: tools found on your PC are shown; missing ones share one line. Usage still comes only from local logs, read-only. Booki never reads accounts, tokens or credentials and makes no network request for it.

## Look and motion

- **Glass is Windows 11 acrylic**, with its own light and dark version instead of one light veil for both.
- **Magnification at any refresh rate.** The dock follows the pointer with smooth, time-based motion: equally quick at 60, 144 or 240 Hz, smoother at higher rates, without overshoot, and it eases back to rest. High-rate mice feed the latest position between frames.
- Menus slide in from the side they open toward, like Windows 11. Panel meters animate on the GPU.
- Colour pickers use Windows 11 swatches with a check on the chosen one and an exact hex field.

## Plugins

- **Plugin updates.** Booki checks a minute and a half after starting, then every six hours, whether its own copies of your plugins are older than the versions this release ships, and offers the update. Updating replaces the plugin in one step; if it is busy (a download, for example) Booki says so and keeps the old copy working. Widgets keep their settings.
- Each plugin card has an icon and says which widget it feeds. Plugins configure the existing widget, even inside a group, instead of adding another.
- Notices and the update pill share a lane outside the dock on all four edges and can be dismissed.

## Windows integration

- Work-area changes (for example the taskbar moving) reposition the dock even when its size stays the same.
- Widget settings link to the matching Windows sound, battery and date settings.

## Not verified on a Windows PC

Automated tests run the interface in a browser with a simulated Windows bridge. The following still need a real PC: the installed upgrade from 0.95.1, native acrylic, plugin updates, Do not disturb, peripheral batteries, and mixed-DPI or multiple-monitor setups.
