# Booki 0.70.2 — Coherent surfaces and usable controls

Choose one material for the dock and notch. Glass, mica, tinted and solid finishes now share a single selector, with a visible selected state and color/opacity controls in the same group. Changing a finish preserves the user's theme, icon size, spacing, rounding, accessibility preferences and pinned apps.

- Preserve stylesheet precedence across production chunks with explicit CSS layers. Legacy Settings rules no longer override the white workspace, card sizing and typography.
- Calculate opacity once for every material and use the same value in the preview and live dock. Use the same bar radius in both views, preserve fractional geometry until physical DPI rounding, and keep text readable over opaque custom tints. Solid finishes can also use a custom color.
- Coalesce native material requests to the latest shape with at most one request in flight. Queue disabling after pending application, keep native blur hidden while opacity/geometry animates, and resume after motion settles. Color/opacity edits no longer reset the native compositor effect. Honor the system's reduced-transparency preference without changing the saved material.
- Fix Settings close: Tauri's close-request handler destroys the window after saving, and its required permission was missing. Scope that permission to Settings, await the actual operation and offer retry when it fails. Pending edits are recorded before React renders, so a quick close still saves them. Updates keep the window hidden while downloading or ready.
- Create Settings groups as one complete edit after selecting at least two existing items. Cancel preserves the dock; creating a group no longer saves an empty placeholder that dissolves after its first member.
- Remove the floating create-group hint when a drag is released, including normal merges and unpin actions.
- Place the searchable app library before the pinned-item editor. Add source filters, explicit add labels, accessible selection state, separate file/folder browsing and a quieter toolbar. Keep bulk selection across queries and pages. The dock add panel also has refresh and keyboard-operable tabs. Shared flyouts fit the available viewport, keeping headers and close actions visible while the contents scroll.

Existing configuration and profile files are retained. Superseded downloads are archived as private drafts after the replacement release is verified; tags and source history remain.

Validation includes browser regressions for material selection, alpha/radius agreement, delayed native commands, long reveals, close/save ordering, close retry and drag-hint cleanup, plus native fractional-DPI geometry tests. CI also checks native Windows compilation, tests and x64/ARM64 packages. Browser fixtures and packaging do not establish compositor behavior on every Windows/GPU combination; desktop appearance, upgrade and uninstall retention still require an interactive Windows check.

Production-build screenshots use example data; they are not native Windows compositor captures.
