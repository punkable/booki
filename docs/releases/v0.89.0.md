# Booki 0.89.0

## Collector
- **Drag a link from the browser.** A link or video dragged onto the notch or the dock reaches the Collector. Before, nothing accepted it while the dock was tucked away, which is most of the time.
- **The notch takes drops.** It has the same drop target as the dock: a drag over it reveals the dock and the drop lands there.
- **More reliable drops.** The drop target is registered again once WebView2's windows exist; a miss used to let WebView2 discard links.
- **Instant start.** A link dropped right on the Collector card starts downloading at once (video for a media page), with a "Drop to download" hint. Dropped elsewhere on the dock, it opens the panel that asks Video or Audio only.

## Widgets
- **Devices:** each device can get its own card on the dock ("Own card on the dock" in the Devices panel). The card follows only that device, with its kind icon and a short name without the brand: "SteelSeries Arctis Nova 7" shows as "Arctis Nova 7".
- **Updates:** Skip hides an update until a newer version of that package appears.
- **AI usage:** Claude always shows.
  - Booki reads Claude Code's sign-in from `CLAUDE_CONFIG_DIR`, `~/.claude`, `%USERPROFILE%\.claude` and Windows Credential Manager.
  - An expired sign-in says "Open Claude Code to refresh sign-in" and is never refreshed behind Claude Code's back.
  - With only the desktop app installed, it asks you to sign in to Claude Code.
  - The OpenAI icon now matches.

## Notch
- **Card only when useful.** Hovering opens the card only when something is live or playing. An idle notch no longer grows into a clock card over your work.
- **Timing.** It waits 350 ms before opening and closes 160 ms after the pointer leaves. It closes even when the window misses the pointer leaving.
- **Alignment and shadow.** The floating pill lines up with the bottom of the dock. A leftover rule had brought back a shadow that the pill's window cut off; it is gone.

## Plugins
- **Tools already on the PC.** OpenRGB, rclone, yt-dlp, FFmpeg and the others count as installed when they are on PATH, or where winget, Scoop, Chocolatey or their own installer put them.
- **Settings.** Those tools are marked "On this PC". Booki uses them as they are and never removes them.

The browser tests cover these flows. Drag and drop from a browser, devices, Claude's sign-in and plugin detection still need a physical Windows PC.
