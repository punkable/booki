# Booki 0.70.1 — Settings and surface stability

- Fix a blank Settings window when opening Home with widgets that have no custom style. The preview now accepts the explicit `null` values serialized by the native backend, without modifying saved pins or widget preferences.
- Keep Settings navigation available if an individual section fails to render, with a retry action. Reopening Settings also shows a window retained during an active update.
- Use the same four corner radii for CSS and native material, including the straight edge of an attached notch. Remove the additional system border/rounding and inset outlines.
- Use native blur without an additional tinted acrylic box. Confirm native material application before disabling CSS blur; keep the same configured CSS fill in both paths. On failure, keep the CSS fallback and throttle retries; ignore obsolete replies. Solid finishes do not create a second native material layer.
- Render release-note icons as graphics, including the previously displayed `sparkles` text.
- Include the real `config.bak.json` recovery file in pre-update snapshots.

Existing settings and profiles are preserved. Automated coverage includes native-format widget records, every Settings section, release-note icons, material fallback and corner geometry at multiple scales. Full Windows desktop composition remains a real-device verification item; browser tests and packaging do not prove its appearance on every GPU/Windows version.

This is the replacement download for previous releases. Updater artifacts are signed; this is separate from Windows Authenticode signing.
