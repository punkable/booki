# Booki 0.83.0

Booki can dress like Windows or like your wallpaper, and dragging apps into groups in Settings now works on Windows.

- **Colors that follow Windows.** Settings > Dock > Colors has three choices. "Like Windows" uses the Windows accent color (which Windows itself takes from the wallpaper when the accent is set to Automatic), follows the Windows mode the way the taskbar does, and tints the glass with a deep shade of the accent when Windows shows the accent on the taskbar. "Wallpaper" samples the wallpaper and tints the dock with it. Both update when Windows or the wallpaper change. "Pick" keeps the colors chosen by hand, and is what existing setups keep.
- **A suggested palette.** Picking an accent (or a widget's color) now leads with Booki's tan and a set of Pantone Colors of the Year that suit Booki's warm look: Mocha Mousse, Peach Fuzz, Living Coral, Classic Blue and others. The picked color is named under the swatches. Any other color is still one click away. The glass colour gains deep Mocha and Cloud.
- **Group dragging in Settings works on Windows.** The Settings window let Tauri's file-drop handler take over WebView2's drop target, so dragging apps into and out of groups in Settings > Apps did nothing on Windows (it worked in the browser preview, which is where it had been tested). The handler is off for Settings, which takes no file drops.
- **Spring-loaded groups in Settings.** Resting on a group while dragging opens it in the side panel; drop the app between its members, or drag members to reorder them. Dragging carries just the icon, and the item being moved dims.

## Verification limits

Automated browser tests use a simulated Windows bridge. Reading the accent and taskbar settings, the wallpaper sampling and HTML drag and drop in the Settings window need to be checked on a Windows 11 device.
