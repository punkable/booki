# Booki 0.93.0

## Agents and local notices

- Full provider name and logo beside separate working, paused, finished and error indicators. Claude Code uses its mascot; Cursor uses its cube. Marks are embedded locally.
- A compact agent capsule avoids cropped names and oversized notices. Cursor recognizes editor TXT/JSONL transcripts and CLI sessions, excluding neighboring terminal and MCP files.
- Activity-only providers remain heuristic. A pause does not prove a permission request; an explicit Codex error is displayed as an error.
- Scheduled Codex resets and the end of Claude's local five-hour block can notify while the dock is hidden, without an AI tile. A completed local block does not confirm recovered quota. Cursor's quota reset date is not available from the watched metadata.
- Deduplicated, minimal local reset metadata survives restarts. Credentials, conversations and account identifiers are not copied into those snapshots. Notices wait during focus, Do not disturb, games and video.

## Collector and dock

- Requesting audio uses a separate output stem, so extraction cannot reuse and remove a previously saved video. Original titles, bounded progress and useful failures are preserved.
- Direct files, galleries, video and audio keep their existing tool-specific routes. Download exclusion remains enforced natively across windows.
- Group colors and icons can be changed from the context menu. Chosen surface colors get readable contrast, and Always visible no longer disappears merely because an ordinary app is maximized.
- Improved Logitech device reading and foreground classification.

## Updates and documentation

- Update notices open System. Changelog history loads on demand, remains folded, uses SVG icons, avoids duplicate versions and offers retry.
- Download and installation remain separate, explicit steps; settings are saved and backed up before applying. MSI and portable copies retain their manual installer route.
- Booki Dev has separate identity, data and blue branding; it cannot consume the stable update feed.
- English/Spanish README, versioned x64/ARM64/MSI buttons, captions and twelve current example-data screenshots are prepared together. Release checks reject outdated documentation or screenshots.

Browser screenshots show the actual frontend with synthetic example data, not a person's desktop. They do not demonstrate native acrylic or ARM64 runtime behavior. Cancellation and resumable Collector queues are not part of this release.
