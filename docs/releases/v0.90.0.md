# Booki 0.90.0

## Native acrylic everywhere
- **Real acrylic on every panel.** Widget panels, the note pad, notices, dock tooltips and the drop hint now sit on Windows' real acrylic, like the bar, folders and menus. Before, they used a CSS blur that only sees the page, which read as a flat second sheet.
- **One Fluent recipe.** Every floating surface uses the same layers: acrylic, tint, a faint grain, a hairline and the flyout elevation shadow.
- **Shadows are never cut.**
  - The dock's shadow used to reach 42 px below the bar, but its window leaves at most 18 px, so the window edge cut it into a band.
  - The notch card's 32 px shadow was cut by its window.
  - Both are now tight enough to fit, and flyouts keep 16 px to the window edge.

## WinUI 3 look
These changes come from an audit against Fluent 2 / WinUI 3, with screenshots of every surface in both themes.
- **Menus** follow MenuFlyout: 32 px items, 16 px icons and full-width dividers.
- **Tooltips, folders and panels** use WinUI padding, 4 px and 8 px corners and a single flyout shadow. Gloss, glows, blur-in and bounce are gone.
- **Controls:** buttons, text boxes, checkboxes and slider thumbs follow the WinUI specs.
- **Settings:**
  - Cards are neutral and have no shadows.
  - The selected navigation item has a pill.
  - Text follows the WinUI type ramp, with only two weights.
- **Motion:** Fluent's decelerate and accelerate curves, with no overshoot.

## Fixes
- **Collector:** a link dropped while its panel was open closed the panel and lost the link.
- **Focus after a drop:** a link drop now gives the dock focus, so a click elsewhere closes the panel.
- **Notch:** turning "follow the taskbar" on or off moves the notch again.
- **Plugins:**
  - Booki searches only absolute PATH entries when looking for tools you already installed, so it can never run a same-named exe from its working directory.
  - FFmpeg is now found in its `bin` folder.

The browser tests cover these flows. The native acrylic still needs a physical Windows 11 PC to check.
