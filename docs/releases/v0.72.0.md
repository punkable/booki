# Booki 0.72.0

A clearer workspace with better editing, keyboard navigation and recovery.

## Library and folders

- The editable dock reserves its own space while you search and scroll. It does not float over apps. Actions have visible labels, selection checkboxes sit beside icons, and short windows keep pin names readable.
- Select apps before adding them, drag into positions or groups, edit multiple items and undo changes. Known Windows folders follow the selected destination.
- Windows utilities are grouped in a searchable section. Icon refresh retries failed extraction, and shortcuts prefer their declared shell icons.
- Browse folders inside Booki with breadcrumbs, search across the complete directory, sort results or open the current location in Explorer. Failed requests preserve the previous view and offer retry.

## Settings, profiles and widgets

- Shared spacing, system typography and quieter selections keep controls consistent. Keyboard focus remains visible even with pale custom accents, and Escape closes details and returns focus to the selected item.
- Home distinguishes failed profile loading from an empty list and offers retry. Widget filtering preserves a customized draft, with responsive controls and previews of saved styles.
- Profiles provide previews, summaries, explicit replacement review, duplication and recoverable deletion. Applying or recovering configuration protects unrelated edits and retains errors for retry.
- Capability-checked native Settings Mica has a solid fallback. Dock material changes avoid unnecessary repeated compositor updates, and Booki app hints replace native title tooltips.

## Data recovery and interaction fixes

- Notes save an atomic recovery journal encrypted with Windows DPAPI before configuration commits. After an interrupted or failed save, Booki offers a preview and explicit Restore or Discard. Failed journal reads block overwriting unread recovery.
- Task and timer edits resolve the current widget after configuration recovery, retain failed input and refuse to recreate removed widgets. Closing a tool panel stops its rendering timer.
- Dock menus ignore late responses after dismissal. Empty groups remain recognizable, group editing retains cancellation, and Settings remains available from Booki context menus.

Existing configuration is preserved. Install the update over your current copy; there is no need to uninstall or create a second installation. Registered per-user installations can download through Booki's updater; applying the update still uses the installer. MSI and portable copies should keep their existing installation type.

## Downloads

Choose the x64 setup for Intel/AMD Windows PCs or ARM64 setup for Windows on ARM. The x64 MSI is available for managed installation. Setup assets have updater signatures; these are not Windows Authenticode signatures.

## Verification limits

The local frontend suite passes 200 tests, with additional layout, contrast, keyboard and pointer checks. The release pipeline repeats frontend checks, runs native Windows tests and builds signed updater packages for x64 and ARM64. Cross-compilation does not establish ARM64 runtime behavior. Physical multi-monitor/DPI, GPU composition and Windows performance measurements remain pending; no measured native speed improvement is claimed. Text within the notes autosave debounce window is not guaranteed after forced termination.
