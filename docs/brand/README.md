# Booki visual identity

Booki should feel calm, clear and approachable. Product communication uses white backgrounds, generous space, elegant sans-serif typography and restrained motion. The capybara and warm accent give it its own personality.

## Presentation

- Use the official `assets/brand/svg/logo.svg` wordmark on white. Keep the original proportions and colors; do not redraw the logo.
- Use white as the main surface, near-black (`#1d1d1f`) for headlines and neutral gray (`#6e6e73`) for supporting copy. Use warm tones sparingly, taken from the capybara.
- Set presentation text in Inter, bundled with its SIL Open Font License in `tools/presentation/fonts/`. Prefer short sentences, generous margins and one clear idea per scene.
- Show the real interface in its light theme. Use sample data and identify unreleased previews. Product renders do not prove native Windows behavior.
- Use soft shadows, gentle camera movement and fades to white. Keep decorative elements minimal so the product remains the focus.
- Publish the main README, featured film, release notes and project communication in English. Keep localized interface strings and optional translated documentation.

## Application

Booki uses Windows system typography (Segoe UI) and supports light, dark and system themes. Respect saved theme preferences. Marketing uses the light theme to express the visual identity; it does not remove the dark theme.

## Source material

SVGs in `assets/brand/svg/` are the official shipped artwork. PNG exports here remain useful source material. Historical native captures in `docs/screenshots/` are retained. Finished product media live in `docs/presentation/`; production instructions are in `tools/presentation/README.md`.
